# A server never mixes Releases

A Knowledge Base may hold several Releases side by side (`cst-2024`, later `cst-2025`) plus release-independent Collections such as example PDFs. Results from different Releases in one answer would let an agent combine a method from one version with an installation of another, so a server serves exactly one Release, together with the release-independent Collections. Consulting another Release means another server. Release-independent Documents state the CST version they were written for where it is known.
