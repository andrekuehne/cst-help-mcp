# The repository ships tooling only; each user builds from their own licensed documentation

CST Studio Suite documentation is Dassault Systèmes' copyrighted material, licensed to each CST user. This is internal tooling in a private repository and is never published. The repository holds the build and serving tools, example configuration and tests. The licensed corpus and built Knowledge Bases are not committed: they are large, and each user builds from their own installation. Within the repository, short vendor excerpts are fine wherever they help: quoted text in test assertions, research notes and benchmark questions, and fixtures cut from real pages.

## Consequences

- Publishing the repository, or anything built from it, would need this decision revisited, starting with removing vendor excerpts from tests and fixtures.
