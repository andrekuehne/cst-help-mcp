# 24: Guides

**What to build:** Guides become possible (ADR 0010 as amended): agents write them, as Markdown with Locator citations, into the workspace's `guides/` folder. The package ships Guide-writing skills, one per topic family, and every assembly copies them into the workspace. `AGENTS.md` lists every Guide, and `validate` checks that every Locator a Guide cites exists. There is no Guides Collection and no ingestion.

**Blocked by:** 15

**Status:** ready-for-agent

- [ ] Skills exist for the first topic families: VBA history commands, Result Template anatomy, dialogs, settings storage, and `cst.interface` sessions. They contain no vendor text, and they say that a Guide carries frontmatter (topic, Release, generated by) and cites Locators.
- [ ] Assembly copies the skills into `.claude/skills/` and `.agents/skills/`, and lists `guides/*.md` in `AGENTS.md`, marked as generated.
- [ ] `validate` reports every cited Locator that does not exist in the folder.
- [ ] A synthetic fixture covers a Guide with a missing Locator.

## Comments

**2026-10-25.** Rewritten for ADR 0014: no `guides-folder` Source, no identifier check, no ranking rules. The identifier check can return as a grep against `api.md` if invented methods turn up in Guides.
